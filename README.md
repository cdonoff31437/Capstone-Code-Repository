This repository includes all code used for the capstone final project:
  "The Negative Effect of Surveillance Capitalism Leveraging Data from Social Media " by Castine Donoff

The files include:
- DecisionTreeOpt: Python Code
-     Original decision tree model and testing of hyperparameter tuning, feature engineering, and explainability
- DecisionTreeTesting: Python Code
-     Testing for cross validation, error analysis, and reliability metrics
- Student Social Media Addiction: Excel File
-     Data used for training and testing, source: Shamin, A. [adilshamim8]. (2026). Social media addiction among students [Kaggle notebook]. 
      Kaggle. https://www.kaggle.com/datasets/adilshamim8/social-media-addiction-vs-relationships
